### Dataset Overview

# OwnLife_2023

### Data Description

OwnLife_2023 is a  wearable/vitals time-series dataset. It contains repeated physiological measurements (blood pressure, heart rate, blood oxygen, respiratory rate, temperature, glucose) and activity metrics (steps, calories, distance, sleep stage), alongside static demographic/biometric attributes for the tracked subject.

- **What the dataset contains**: Time-stamped vitals and activity readings for each subject, plus constant demographic/anthropometric fields (age, sex, height, weight, skin type, BMI).
- **Primary use cases**: Time-series analysis of vitals, sleep-stage/activity correlation studies, personal health trend tracking.
