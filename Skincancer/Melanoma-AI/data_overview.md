### Dataset Overview

# Melanoma-AI

### Data Description

The Melanoma-AI dataset is an internally collected image dataset organized by upload batch. Each batch generally contains a set of original lesion images (often labeled _Axes), a corresponding set of segmented images (_segments), and in some batches, annotation spreadsheets. Batch numbers are not sequential — batches 3 and 6 do not exist, and batch 8 contains only an annotation file with no image folder.
