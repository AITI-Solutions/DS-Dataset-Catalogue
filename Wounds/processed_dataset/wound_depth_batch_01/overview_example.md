### Dataset Overview

# processed_dataset_wound_depth_batch_01_new_path

### Data Description

This is an image-path-to-label mapping file for wound depth classification, covering images from "batch_01" of a processed wound dataset. Each row pairs a relative image file path with a wound depth label.

- **What the dataset contains**: Relative paths to wound images, each labeled with a wound depth classification.
- **Primary use cases**: Wound depth classification (Deep / Dermal Layer / Epidermal Layer).
- **Key entities or metrics included**: Image file path, depth label.
